# TextToPNG tool (v0.2.0)

Why would you need this? Well, welcome to the world of small projects. A world full of pretty useless and yet interesting stuff! I (AKA @Dalufi] am very thankfull for your visit. I just wanted to learn and practice python and this was the result. The idea is simple, just get some Text and slap it on a PNG and you're done! But that'd be boring so I'll be trying my best to expand this tool as much as possible so you can do more stuff like changing the font, size of the text etc. But in the end there's **one thing** I want to achieve: Doing most of the code myself. As of right now everything including the assets were made by me (except the libraries and Pre-installed fonts). Have fun!
